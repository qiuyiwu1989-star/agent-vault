# 榨书

先说明输入覆盖：全文、节选/笔记，或仅书名。仅书名时说明未经原书核验，不编造章节、引语、数字或原书案例；不确定就标注不确定，不能用“据作者论述”掩盖。

六阶段：真问题 → 核心模型 → 迁移测试 → 前提/反例/边界/成本 → 行动接口 → 情境检验。模型数量由材料决定。迁移示例与原书案例明确区分。

有可访问的既有档案时才做跨书关联，并指向实际记录。外部记忆、飞书和消息同步都是可选的实例能力；没有用户授权或实例规则时不执行。

输出遵守仓库 `docs/contract-v1.md` 的 books 字段和统一命名。要求归档时依照 `skills/vault-maintain/SKILL.md` 提交，勿同时维护另一套元数据模板。发布状态按工具结果报告。
