# 知行档案体验契约 v1

1. **找到再返回**：公开搜索与分类URL可匿名刷新；深链不能意外进入鉴权。详情只有一个栏目返回入口。登录返回保留路径和查询。
2. **身份明确**：公开栏目与个人收件箱分开；工作区提供公开出口。匿名批注只存当前浏览器，账户批注属于当前账户，不自动把本机记录上传。
3. **笔记能找回**：工作台汇总旧阅读器笔记与当前账户的公开页批注，显示来源，按更新时间排序。公开批注查询限制owner_id、namespace=vault、未删除。两套存储原样保留。编辑按来源回写原系统且校验版本。旧笔记沿用已有工作台访问边界，不擅自重新分配归属。
4. **导出可判断**：讨论材料默认不含私人笔记；仅显式勾选后包含，并使用当前账户可见的聚合结果。MCP读取不得因这轮升级扩大到私人批注。
5. **失败保留劳动**：保存失败不清输入、请求期间禁用重复提交；冲突要求重新打开比较，不覆盖新版本。保存草稿与公开发布不同。
6. **状态有含义**：加载、首次为空、筛选为空、网络失败、401、版本冲突分别说明；错误状态可感知，不能只变色。后台status与msg有role=status。
7. **内容可追溯**：书籍资料范围、来源、编辑示例与旧稿分开；旧稿回当前版本。作品链接回原站时提示是归档展示。
8. **移动可操作**：正文页面不横向撑宽；表格在区域内滚动；手机图解可转顺序卡片。不得用overflow:hidden把内容直接裁掉。
9. **键盘可完成**：栏目菜单Enter/Tab/Escape；正文选区监听键盘；划线标记可聚焦编辑；返回焦点清晰。屏幕阅读器需真实设备单独验收。
10. **统计口径明确**：归档份数不是阅读次数；公开快照与后台证据范围分别说明。私人笔记指标包含工作台和当前账户批注，不包含其他账户、本机笔记或删除记录。

执行与证据见 Spec003。后台生产真实账户写入不以合成样例冒充验收；目前路由、权限过滤、私密导出规则有自动测试，界面用隔离数据验证。全量对比度、VoiceOver和跨浏览器长期回归仍需按每批版本持续复核。
