# 爪爪文字采集与体验数据：实施计划

2026-10-13。目标：复制文字或导入 Markdown → 自动保留草稿 → 编辑图文笔记 → 原图存 COS、正文存数据库 → 知行档案展示与搜索。

## 本轮并行工作

| 分工 | 交付 | 验收 |
| --- | --- | --- |
| 桌面端 | 中央添加区文字入口、md/txt 导入、编辑与预览、本地草稿、版本同步、图片附件 | 原有图片功能不退化；关闭/重开保留草稿；失败可重试 |
| 后端 | 独立笔记数据模型、认证 API、版本冲突检测、附件关联、搜索分页 | Markdown 原文回读一致；重试不重复；旧版本不能覆盖新版本；匿名不能读写 |
| 网站 | 图片/笔记筛选、笔记摘要和详情、新建与编辑、草稿恢复 | 图片仍为纯图片瀑布流；Markdown 安全渲染；保存失败不丢失输入 |
| 主 Agent | 接口对齐、集成验证、部署回退、任务记录 | 实际运行路径与未验证边界明确 |

## 体验数据

只收集白名单操作类型、来源、成功/失败、耗时、结果数量和固定错误码。不收集正文、OCR、剪贴板、搜索词、文件路径、来源网址或设备标识。提供开关；埋点失败不得阻断保存。后端只供已认证用户查看聚合，并设置事件保留期限。

优先回答：哪里保存失败、同步等待多久、搜索是否无结果、预览是否慢。技术事件不占据笔记主界面，不把未经验证的指标当作用户体验结论。

## 后续批次

1. 浏览器选中文字右键采集、网页正文摘录和来源保留（独立扩展）。
2. macOS 分享/服务入口、批量导入、版本历史与冲突合并。
3. 根据第一轮真实事件判断搜索、加载和采集入口的优化优先级，再决定语义搜索等能力。

本轮保留 Markdown 数据源与图片引用，不把图文笔记扁平化成截图。当前单人私有空间，未扩展为多人协作系统。
