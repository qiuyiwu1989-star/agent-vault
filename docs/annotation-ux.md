# 网页批注交互设计 · v0.2

## 阅读时

用户进入文章时只见右下角「我的笔记」按钮，正文排版保持原样。选中正文后，选区旁出现小卡片：引用、五种划线颜色、可选评注、保存/取消。颜色分别是黄色、珊瑚、薄荷、天空、淡紫；当前颜色有明显边框和文字名称，颜色不是唯一识别方式。无评注也能保存划线。服务器只接受这五种颜色；历史记录未标颜色时按黄色显示。

## 回看时

已保存的划线以半透明色块覆盖在原文中，刷新后重绘；有评注的段落右缘显示 ✎ 提示。点击提示或原文划线后，右侧笔记栏移动到对应文字的上下位置，滚动时继续跟随，并选中该条详细内容。右侧支持收起、紧凑、展开三态；点列表项滚动到原文并打开就地编辑卡片。移动端选区卡片固定在底部，右侧栏改为底部抽屉。键盘可进入笔记列表并按 Enter 打开。正文变化时无法确认位置的笔记仍保留在列表，并标「原文位置待确认」。

## 接入与权限

浏览器 SDK 不包含 Vault 地址、账号或数据库逻辑。宿主提供正文容器、稳定文档标识及 list/create/update 适配器。Vault 登录用户的笔记仍走服务端，按 owner/namespace/document 隔离；自动化 Bearer 不可冒充。未登录用户使用按站点与文章路径分隔的 localStorage 草稿，仅在当前浏览器可见，不向服务器上传，也不会自动合并到登录账户。清除网站数据或更换浏览器会失去这些草稿。颜色与评注共同受版本冲突校验。

## 验收清单

桌面：五色依次保存、同页两处不同颜色、刷新后颜色不变、点击原文划线打开评注、改色改评注后同步更新、右栏三态可用、选区不误包含导航。移动端：长按选区、底部编辑卡片、抽屉不遮挡输入。异常：未登录、正文变动、重复引用、网络失败、两处并发编辑、旧黄色笔记。自动测试覆盖颜色集合和双账号后端读写；真实浏览器操作另行验收。
