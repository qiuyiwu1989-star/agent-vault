## 网站统一结构

个人主页（了解人和作品）→ 知行档案（查找与阅读）→ 内容详情（阅读、看来源、记笔记）。个人工作台为独立管理入口：应用中心 → 选择应用 → 在应用内完成任务 → 返回应用中心。公开内容不应因普通阅读动作跳到登录后台。

栏目页是首页内容的分组视图；首页必须继续聚合全部栏目。同一内容只有一个主要阅读地址。标题和按钮必须指向同一地址。内容类型与来源平台分别显示，视频不以抖音/B站作为栏目名。

## 已实施

- 聚合首页收紧标题区，减少到达内容前的滚动；移除无真实图像的重复书/思字样大封面。
- 六个栏目筛选显示内容量，顺序与导航一致；搜索支持作者账号和来源。
- 筛选和查询写入 URL，刷新或返回后恢复；提供清除筛选和加载失败重试。
- 卡片标题与行动按钮统一打开公开内容，视频使用“打开视频档案”，作品使用“查看作品”。显示已记录的平台及账号，不猜来源。
- Agent 接入资料改为中文任务名称和分组卡片，保留版本与技术标识，补充三步使用路径。保留已有复制配置和授权逻辑。
- 共享样式补充可见键盘焦点、44px 导航与筛选目标、移动端搜索优先、减少动态效果支持。

## 全站后续开发统一标准

| 对象 | 规则 | 验收动作 |
|---|---|---|
| 导航 | 全站入口、栏目、当前页三层分清；当前位置可见 | 从任意详情返回所属栏目和首页 |
| 操作 | 一屏一个主操作；文字说明动作，不单独依赖图标 | 新用户能复述点击结果 |
| 搜索 | 输入保留、有结果数、无结果可清除、失败可重试 | 搜索→打开→返回，条件仍在 |
| 可视化 | 用数量、来源徽章、流程阶段表达真实数据；无数据不编造图表 | 图表点击可追溯内容，注明统计范围 |
| 表单 | 输入示例、必填字段、就近报错；保存成功显示结果 | 错误后输入不丢失，保存后可重新打开 |
| 状态 | 加载/空白/失败/成功区别显示 | 慢请求、空集合、异常均有下一步 |
| 阅读 | 正文优先，来源与笔记辅助，不强迫进入后台 | 阅读→划线→保存→重开验证 |
| 移动端 | 搜索易到达；导航可换行；操作不遮正文 | 390px 无横向溢出，触摸目标足够大 |
| 无障碍 | 焦点可见；按钮用原生 button；不用颜色单独传递状态 | 键盘可完成主要任务 |
| Agent 接入 | 先说明能做什么，再展示配置；技术资料渐进展开 | 选技能→复制配置→验证→定位错误 |
